# 新竹升學練習室

## 使用方式

雙擊 `index.html` 開啟網站。也可在此資料夾執行 `python -m http.server 8000`，再開啟 http://localhost:8000/ 。

- Excel 收錄的 113–115 學年度三校題庫拆成數學、自然（含理化）、國文、英文與英聽。共 31 份可計分的分科題本、1053 題。
- 交卷以各卷官方答案批改，依答對比例換算百分制，四捨五入至整數。空白題為零分。錯題練習收錄該科所有曾選錯的題，去除重複題號，答對後仍可再練。未答題可在個別交卷紀錄檢視。每份考卷的成績頁可依選取的作答紀錄重做這份錯題，重練成績另存。
- 同一瀏覽器會保存各卷草稿、歷次成績和錯題。舊版慈濟數學卷的作答紀錄會在同一網址下移轉。字級可用右上角 A−／A＋ 調整，原卷圖像亦可隨字級放大並捲動。
- 家長密碼為 `5168`，每次解鎖一題。網站為純前端，答案與密碼可由原始碼讀取。慈濟 115 數學、瀛海 113–114 自然及瀛海 114 數學大部分題目提供解題說明，其餘可核對官方答案。
- 題本保留原圖、選項與題號。閱讀題組若跨頁，可使用題本上一頁／下一頁查閱。自然原卷含物理、化學、生物與地科。

## 部署

將此資料夾完整放到 GitHub 儲存庫根目錄，包含 `bank/`、`figures/` 與 `.nojekyll`。所有網站資產使用相對路徑。

- GitHub Pages 選從分支部署，發布來源為網站所在分支的根目錄。
- Cloudflare Pages 連接 GitHub 後，框架選 None，建置命令填 `exit 0`，輸出目錄填 `.`。
- 部署後可從平板開啟網址。同一平板若以其他瀏覽器、無痕模式或不同網址開啟，會有各自的作答紀錄。
